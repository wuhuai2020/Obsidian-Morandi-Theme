# 第一步：了解知识库结构

你的知识库遵循「输入 → 沉淀 → 加工 → 输出 → 复用」的流动闭环。每一层只承担一种主要职责，让信息保持安静、清晰并且可追溯。

```mermaid
flowchart TD
    A[输入] --> B[沉淀]
    B --> C[加工]
    C --> D[输出]
    D --> E[复用]
    E -.反馈.-> B
```

| 层级 | 功能 | 关键词 |
| --- | --- | --- |
| 输入层 | 捕获一切灵感和信息 | 记录、收藏 |
| 沉淀层 | 建立永久记忆 | 人脉、公司、工具 |
| 加工层 | 组织与提炼内容 | 项目、分析、连接 |
| 输出层 | 形成可以发布的结果 | 文章、报告、分享 |
